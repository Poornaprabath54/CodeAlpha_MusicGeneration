# LINGUORA — CodeAlpha Task 1

## Run in Windows Command Prompt

cd CodeAlpha_Task1_Linguora
py -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py

Open http://127.0.0.1:5000

The local `.env` contains the DeepL key supplied for this project. Do NOT publish `.env` to GitHub. `.gitignore` excludes it.
